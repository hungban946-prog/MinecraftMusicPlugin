Có gì trong app?

Chat riêng tư

Lịch sử trò chuyện được lưu trên điện thoại; không cần tạo tài khoản.

Làm việc với file

Đính kèm và đọc tài liệu, tìm nội dung, tạo file văn bản hoặc xử lý ZIP.

Tự cấu hình API

Nhập Base URL, model và API key của nhà cung cấp tương thích OpenAI.

Lưu ý trước khi dùng

Bạn cần tự cung cấp API key. Key được lưu trên thiết bị, không chia sẻ APK đã cấu hình key. Khi chat hoặc gửi file, nội dung liên quan sẽ được gửi đến API bạn đã chọn.

APK được tạo từ mã nguồn công khai của dự án. Xem các bản phát hành.
